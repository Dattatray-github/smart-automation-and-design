# Smart Automation and Design website

A responsive one-page starter website for Smart Automation and Design.

## Preview locally
Open `index.html` in a web browser. Internet access is needed for the sample images hosted on Unsplash.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your public GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Before publishing publicly
- Replace sample images with photos you own or have permission to use.
- Add your business email in the JavaScript variable `businessEmail`.
- Configure the WhatsApp link with your verified business number.
- Review all service descriptions and training topics for accuracy.
- If you want forms to submit without opening an email app, connect a form backend/service.
- Add a privacy policy if you collect personal information.
- GitHub Pages is static hosting and has usage restrictions; review GitHub's current terms for business use.
