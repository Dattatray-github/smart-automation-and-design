PPPC Course Curriculum

Professional PLC Programming Certification · Online

Duration stated by client: 3 months Curriculum supplied: 12 weeks · 60 days
Month 1 — Introduction to Automation and PLC Basics

Week 1: Fundamentals of Automation

  1. Overview of Industrial Automation and Control Systems
  2. Introduction to Sensors, Actuators, and Controllers
  3. Basics of Control Systems: Open-loop vs. Closed-loop
  4. Understanding PLC Hardware and Architecture
  5. Introduction to Ladder Logic Programming

Week 2: PLC Programming Basics

  1. Overview of PLC brands (Allen-Bradley, Siemens, Mitsubishi)
  2. Input and Output module configuration
  3. Timers and Counters programming
  4. Hands-on exercises with Allen-Bradley, Siemens, Mitsubishi
  5. Practical troubleshooting of basic PLC issues

Week 3: Intermediate PLC Programming

  1. Analog signal processing with PLCs
  2. Introduction to Functional Block Diagram (FBD)
  3. Practical programming with Siemens PLC
  4. Introduction to Communication Protocols (Modbus, Profinet)
  5. Weekly assessment and review
Month 2 — HMI Systems and Basic SCADA

Week 4: HMI Fundamentals

  1. Role and importance of HMIs in automation
  2. Overview of Siemens and Allen-Bradley HMI
  3. Designing basic HMI screens
  4. Setting up HMI-PLC communication
  5. Hands-on: Real-time HMI project

Week 5: Advanced PLC Programming

  1. Advanced ladder logic programming techniques
  2. Handling complex inputs/outputs and PID control
  3. Troubleshooting complex PLC programs
  4. Introduction to Communication Protocols (EtherNet/IP, Profibus)
  5. Weekly review and feedback

Week 6: Advanced HMI Concepts

  1. Configuring animations and dynamic objects
  2. Working with alarms and data trends in HMI
  3. Multi-language support in HMI design
  4. Troubleshooting HMI systems
  5. Practical: Multi-screen HMI project
Month 3 — SCADA, VFD and Final Project

Week 7: SCADA Introduction

  1. SCADA architecture and its applications
  2. Introduction to Wonderware SCADA software
  3. Configuring PLC-SCADA communication (basic overview)
  4. Designing basic SCADA screens (introduction)
  5. Hands-on: Simple SCADA project setup

Week 8: Variable Frequency Drives (VFD)

  1. Introduction to VFDs and their applications
  2. Setting up Siemens VFDs for motor control
  3. Configuring VFD parameters
  4. Troubleshooting VFD communication issues
  5. Hands-on project: Integrating VFD with PLC and HMI

Week 9: Final Project Preparation

  1. Project overview and requirements gathering
  2. Designing a complete automation solution
  3. Hands-on project work: Programming and integration
  4. Testing the final project setup
  5. Weekly review and feedback
Week 10 — Advanced Troubleshooting
  1. Diagnosing PLC communication issues
  2. Basic SCADA system fault identification
  3. HMI performance troubleshooting
  4. Common VFD faults and resolutions
  5. Real-world examples and case studies
Week 11 — Final Project Preparation
  1. Final project overview and requirements gathering
  2. Designing a complete automation solution
  3. Hands-on project work: Programming and integration
  4. Testing the final project setup
  5. Weekly review and feedback
Week 12 — Final Project Presentation
  1. Documentation and reporting
  2. Performance evaluation and system optimization
  3. Final project demonstration
  4. Certification assessment
  5. Feedback and graduation ceremony
